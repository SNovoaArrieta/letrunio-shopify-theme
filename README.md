# Tema Shopify de Letrunio

Tema propio para la tienda de ebooks de Letrunio. La primera versión está optimizada para presentar y vender **Una noche para dos**, conservando una identidad general que permita incorporar nuevas colecciones.

## Configuración en Shopify

1. Conecta este repositorio desde **Tienda online > Temas > Conectar desde GitHub**.
2. Crea el producto digital y añade su portada, descripción y precio.
3. En el editor del tema, abre **Portada del producto** y selecciona el producto.
4. Carga el logo de Letrunio en **Encabezado**.
5. Añade los enlaces reales de TikTok e Instagram en **Pie de página**.
6. Instala la aplicación oficial **Digital Products** de Shopify y adjunta el PDF al producto.
